# SPRINT 1

Für Sprint 1 würde ich die ersten 7 User Stories vervollständigen, wenn möglich. Dabei spricht man von 19 Story Points.
Ob alle sieben Stories in einen Sprint passen, muss wir als Team anhand einer verfügbaren Kapazität prüfen.

# DEFINITION OF DO

Eine User Story gilt als abgeschlossen, wenn folgende Kriterien erfüllt sind:

### DoD-Checkliste

- [ ] Die Funktion wurde vollständig implementiert.
- [ ] Alle Akzeptanzkriterien der User Story sind erfüllt.
- [ ] Der Code wurde von mindestens einem weiteren Teammitglied überprüft.
- [ ] Relevante Tests wurden durchgeführt und bestanden.
- [ ] Es gibt keine bekannten schwerwiegenden Fehler.
- [ ] Die Funktion ist in die gemeinsame Anwendung integriert.
- [ ] Die Funktion kann in einer Demo erfolgreich vorgeführt werden.

### Aufgabenverwaltung

Der Status der Aufgaben wird in einem einfachen Task-Board mit folgenden Spalten dokumentiert:

| Status | Bedeutung |
|---|---|
| To Do | Die Aufgabe wurde noch nicht begonnen. |
| In Progress | Die Aufgabe wird aktuell bearbeitet. |
| In Review | Die Implementierung wird überprüft und getestet. |
| Done | Die Aufgabe erfüllt alle Kriterien der Definition of Done. |
