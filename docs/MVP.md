# Minimum Viable Product
### Definition fur Max: Einfachste Version der Anwendung, die bereits einen echten Nutzen bietet (nur die wichtigsten Funktionen entwickeln)
### Ziel: einfache Webanwendung entwickeln, in der Teilnehmer Fragen einreichen und bewerten können. Der Präsentierende kann die Fragen nach ihrer Beliebtheit sortiert sehen und als beantwortet markieren.

Dafür wurde ich diese User Stories für das MVP auswählen:

| User Story | Funktion |
|---|---|
| US01 | Professor erstellt eine Veranstaltung |
| US02 | Studenten treten über einen Link bei |
| US03 | Studenten reichen Fragen ein |
| US04 | Studenten sehen andere Fragen |
| US05 | Studenten stimmen für Fragen ab |
| US06 | Professor sieht Fragen nach Stimmen sortiert |
| US07 | Professor markiert Fragen als beantwortet |

Für den ersten Sprint verzichten wir bewusst auf KI-Funktionen, Diagramme, Registrierung und zusätzliche Moderationsfunktionen. Die Anwendung soll zunächst den grundlegenden Ablauf zuverlässig unterstützen.
